# Reviewed single-use dp/sp literals that intentionally stay literal (rule: a value used < 3 times, or a one-off art size).
# Read by tools/check-tokens.ps1 for the dp-layout, dp-spacing and drawable categories.
#
# Format (one entry per line, '|' separated, '#' starts a comment):
#   file|attr|value|reason
#     file   file name only (activity_foo.xml, bg_bar.xml), not a path
#     attr   attribute name without the android:/app: prefix (layout_width, minHeight, paddingTop, radius, ...)
#     value  exactly as written in the file (28dp)
#     reason why it is not a token
# One entry exempts EVERY occurrence of that attr+value in that file. An entry that matches nothing is STALE and fails the check.
